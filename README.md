
# Customer Lifetime Value Prediction

## Description
This project predicts customer lifetime value using
historical purchasing behaviour.

## Dataset
UCI Online Retail Dataset.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Gradient Boosting Regression

## Evaluation
- MAE
- RMSE
- R2 Score

## Implementation
Implemented using Google Colab.
